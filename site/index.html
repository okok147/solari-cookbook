The reliability gap

A click is not a completed task.

Computer-use agents can navigate a UI. The harder problem is deciding what must be true before they act, what to do when an acknowledgement is ambiguous, and what evidence is required before saying “done.”

    The key failure case

    UNKNOWN is not FAILED.

    The lab commits account creation and then returns HTTP 502. Instead of blind retry, Asympta enters UNKNOWN → RECONCILING, reads authoritative sandbox state, adopts the already-completed effect, and continues safely.
